# DevoStudio Bot

A powerful, multi-purpose Discord bot developed by DevoStudio — bringing moderation, fun, utilities, and server tools all in one.

## 🌟 Features
- 👮‍♂️ Moderation (ban, kick, mute, etc.)
- ⚙️ Utility commands (ping, uptime, server info, user info)
- 🎉 Fun commands (memes, games, randomizers)
- 🛠️ Custom tools for server management
- 📡 Constant updates & bug fixes
